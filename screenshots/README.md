# Screenshots à capturer

Voici la liste des captures d'écran à réaliser pour illustrer le projet :

## Ordre recommandé des captures

1. **screenshots/landing.png**
   - Page d'accueil (index.html)
   - Capturer la section hero avec le formulaire de connexion
   - Montrer les cartes de fonctionnalités

2. **screenshots/login.png**
   - Page de connexion (login.html)
   - Capturer le formulaire de login

3. **screenshots/dashboard.png**
   - Tableau de bord principal (dashboard.html)
   - Capturer l'onglet "الطلبات" avec la liste des commandes
   - Montrer les filtres et la recherche

4. **screenshots/dashboard-feed.png**
   - Tableau de bord - onglet "المتابعة"
   - Capturer le feed d'activité en temps réel

5. **screenshots/dashboard-stats.png**
   - Tableau de bord - onglet "الإحصائيات"
   - Capturer les graphiques de performance

6. **screenshots/order-details.png**
   - Page de détails d'une commande (order-details.html)
   - Capturer la conversation et la timeline
   - Montrer les boutons d'action

7. **screenshots/order-details-alert.png**
   - Page de détails avec une alerte active
   - Capturer la carte d'alerte et les options d'intervention

8. **screenshots/print-orders.png**
   - Page d'impression des commandes (print-orders.html)
   - Capturer la mise en page d'impression

9. **screenshots/signup.png**
   - Page d'inscription (signup.html)
   - Capturer le formulaire de création de compte

10. **screenshots/pending.png**
    - Page d'attente d'approbation (pending.html)
    - Capturer le message d'attente

## Instructions pour les captures

- Utiliser une résolution de 1920x1080 ou plus
- Capturer en PNG pour une meilleure qualité
- S'assurer que le navigateur est en mode plein écran
- Zoomer à 100%
- Éviter de capturer des données sensibles (numéros de téléphone réels, etc.)
